# i-dont-like-lg - LG Smart TV (webOS) telemetry / ACR / ad blocklist
# One file. Format: 0.0.0.0 <domain>. Works as a Pi-hole / AdGuard Home adlist or in /etc/hosts.
# Add the raw URL of this file as an adlist:
#   https://raw.githubusercontent.com/rafal-xyz/i-dont-like-lg/main/hosts.txt
#
# Verified against LG webOS 2020 + 2023 models, then merged with public LG lists.
# Region-proof: regional prefixes (us/eu/de/pl/...) are enumerated for the ad hosts.
#
# LEFT WORKING ON PURPOSE (do NOT add these): eic.netflixvoice.lgtvcommon.com (Netflix
# voice search); Netflix/Prime/YouTube streaming; the base lgappstv.com / lgthinq.com
# (LG app store + smart-home still function; only their ad/telemetry hosts are blocked).
#
# WARNING: some webOS firmware uses hardcoded DNS-over-HTTPS and can bypass DNS blocking.
# Also block outbound DoH on your router and do not set a manual public DNS on the TV.
